# Мои деньги: мини-приложение для Telegram

Личный учёт денег: баланс, доходы и расходы, категории, история.
Данные хранятся на телефоне пользователя, на сервер ничего не уходит.

- `index.html`: разметка
- `style.css`: внешний вид (подхватывает тему Telegram)
- `app.js`: логика и подключение к Telegram
